時間の足し算・引き算

基準の時刻に、時間を足すか引きます。時刻は 時:分 または 時:分:秒 の形式で入力します。





使い方のヒント

  • 足す・引く時間は、24時間を超えても入力できます(例: 30:00)
  • 結果が日をまたぐときは「+1日後」のように表示されます
  • 時刻どうしの差を知りたいときは時間差の計算を使います

手計算の考え方は時間計算の手計算を参照してください。

本サイトの結果は目安です。勤怠・契約・航空券などで使う前には、公式の時刻表や各組織の規定など公式の情報で確認してください。入力した値は、ブラウザの中だけで計算され、送信されません。
