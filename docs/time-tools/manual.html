時間計算の手計算のやり方

時間・分・秒は60進法です。10進数の筆算と同じ形で、60を超えたら繰り上げます。

足し算

例: 22:30 に 3時間45分を足す

  1. 分を足す: 30 + 45 = 75分 → 60を引いて15分、時に1繰り上げ
  2. 時を足す: 22 + 3 + 1 = 26時 → 24を引いて2時(翌日)

答え: 翌日の2:15。

引き算

例: 9:20 から 2時間45分を引く

  1. 分が足りないので、1時間(60分)を借りる: 20 + 60 = 80分
  2. 分: 80 − 45 = 35分
  3. 時: 9 − 1 − 2 = 6時

答え: 6:35。

すべて秒に直す方法

1時間=3600秒、1分=60秒に直して足し引きし、最後に3600や60で割って戻すと、繰り上がりを意識せずに済みます。

計算結果は足し引きツールで検算できます。
