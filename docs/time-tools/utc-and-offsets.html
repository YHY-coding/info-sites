UTCとオフセットの基本

UTCとは

UTC(協定世界時)は、世界の標準時刻の基準となる時刻です。各地域の標準時は、UTCからどれだけ進んでいるか、または遅れているかで表せます。

オフセットの読み方

  • UTC+9: UTCより9時間進んでいる(日本標準時)
  • UTC−5: UTCより5時間遅れている
  • UTC+5:30: 30分単位のずれを持つ地域もある

変換の手順

  1. 元の時刻から、元のオフセットを引いて、UTCにする
  2. UTCに、変換先のオフセットを足す

例: 日本の9:00(UTC+9)→ UTCでは0:00 → UTC−5の地域では、前日の19:00。計算は時差変換ツールで確かめられます。

地域ごとのオフセットは制度の変更があり得るため、最新の値は公式の情報で確認してください。主な値の例はオフセット表にあります。
