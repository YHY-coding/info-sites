時間差(経過時間)の計算

開始と終了の時刻を入力します。終了が開始より小さいときは、翌日の時刻として計算します。





注意

  • 1日(24時間)を超える時間差は、このツールでは扱いません
  • 勤務時間の扱い(丸め方、休憩の取り方など)は、会社の規定や公式の資料で確認してください
  • 小数の時間は、小数第2位まで切り捨てて表示します。換算は小数時間の換算でも行えます

本サイトの結果は目安です。勤怠・契約・航空券などで使う前には、公式の時刻表や各組織の規定など公式の情報で確認してください。入力した値は、ブラウザの中だけで計算され、送信されません。
