リージョンとリージョンペア

一言で言うと
リージョンはAzureの地域(複数のデータセンターの集まり)。リージョンペアは、災害に備えて組まれた同じ地域内の2つのリージョン。

たとえ話

リージョン=街。リージョンペア=遠く離れた姉妹都市。

押さえること

  • リージョンを選ぶ基準: ユーザーに近い(遅延が小さい)/法規制・データ所在地/提供サービスの有無/価格
  • リージョンペアは数百km以上離れている。更新はペアの片方ずつ行い、障害時は一方の復旧が優先される
  • 特殊リージョン: Azure Governmentは米国政府機関向けでMicrosoftが運営。Azure Chinaは21Vianetが運営

試験でのポイント

  • 特殊リージョンを「全部外部委託」と一括りにしない

確認問題

Azure Governmentを運営しているのは?

答えを見る
