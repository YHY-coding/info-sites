ドメイン2:Azureのアーキテクチャとサービス

セキュリティ関連サービス(Defender・Sentinel・Key Vault・Purview)

一言で言うと
守る、検出する、金庫に保管する、データを統治する、の役割分担。

たとえ話

警備会社(Defender)、監視センター(Sentinel)、金庫(Key Vault)、書類管理室(Purview)。

押さえること

  • Microsoft Defender for Cloud: セキュリティ態勢管理(CSPM)+脅威保護。セキュアスコア、推奨事項、JIT(必要なときだけVMのポートを開放)
  • Microsoft Sentinel: SIEM/SOAR。オンプレと複数クラウドのデータから脅威を検出
  • Azure Key Vault: パスワード・証明書・APIキー・暗号化キーの金庫
  • Microsoft Purview: データガバナンス。文書やメールの機密ラベルもその一部

試験でのポイント

  • 「資格情報・パスワード・証明書」→ Key Vault、「文書やメールの機密ラベル」→ Purview
  • 「オンプレとマルチクラウドの脅威検出」→ Sentinel
