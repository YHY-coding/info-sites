ドメイン2:Azureのアーキテクチャとサービス

Microsoft Entra ID

一言で言うと
クラウドのID管理サービス(旧Azure Active Directory)。ユーザー・グループ・アプリの認証基盤。

たとえ話

会社全体の入退館システム。

押さえること

  • SSO: 1回のサインインで複数のアプリを使える
  • Entra Connect=同期する、Connect Health=同期を見張る、Defender for Identity=攻撃者を探す、と動詞で覚える
  • 外部ID: B2Bは取引先の招待、B2Cは顧客向けアプリの認証
  • 認証=誰かの確認、承認(認可)=何ができるかの判定

試験でのポイント

  • 「なりすましの検出」→ Defender for Identity
  • 認証と承認は、文が「身元」か「権限」かで判定する
