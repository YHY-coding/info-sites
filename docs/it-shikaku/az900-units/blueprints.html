ドメイン3:Azureの管理とガバナンス

Azure Blueprints(開店キット)

一言で言うと
準拠した環境を、何度でも同じように展開するためのパッケージ。

たとえ話

開店キット。内装・規則・鍵の配布を、セットで用意する。

押さえること

  • 構成: ARMテンプレート+Azure Policy割り当て+RBACロール割り当て
  • 複数のサブスクリプションへの展開に便利
  • 廃止が決まっているサービス。代替はTemplate SpecsやDeployment Stacksなど。最新の状況は必ず公式で確認する

試験でのポイント

  • 「コンプライアンス要件に準拠した、再現可能なリソースの一式」→ Blueprints

確認問題

Blueprintsの構成要素のうち、「タグの標準化」を担当するのは?

答えを見る

Policy(Blueprintsの直接の機能ではない)
