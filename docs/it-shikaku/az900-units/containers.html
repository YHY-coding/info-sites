ドメイン2:Azureのアーキテクチャとサービス

コンテナ(ACIとAKS)

一言で言うと
アプリと必要な道具だけを箱に詰めて、どこでも動かせる軽い仮想化。

たとえ話

VMは家ごと引っ越し、コンテナは荷物を箱詰めして運ぶ。

押さえること

  • VMはOSごと仮想化するので重く、起動が遅い。コンテナはOSを共有するので、軽く速い
  • Azure Container Instances(ACI): コンテナを最速・最簡単に実行(VM不要)
  • Azure Kubernetes Service(AKS): 多数のコンテナを管理(オーケストレーション)する

試験でのポイント

  • 「ポータブルな環境」→ コンテナ
  • 1つ手軽に → ACI、大規模な管理 → AKS
