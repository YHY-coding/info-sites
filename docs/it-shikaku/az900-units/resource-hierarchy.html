ドメイン2:Azureのアーキテクチャとサービス

リソースの階層構造

一言で言うと
管理グループ → サブスクリプション → リソースグループ → リソース、の4階層。上位の設定は下位に継承される。

たとえ話

ビル群(管理グループ)→ ビル(サブスクリプション)→ フロア(リソースグループ)→ 部屋(リソース)。

押さえること

  • 管理グループ: 複数のサブスクリプションにまたがって、ポリシーやアクセス権を一括適用
  • サブスクリプション: 請求とアクセス管理の境界。クォータ(上限)もここ
  • 無料アカウントは、期間経過かクレジットの使い切りで期限切れになる(条件は公式で確認)

試験でのポイント

  • 複数サブスクリプションへ一括適用したい → 管理グループ

確認問題

複数のサブスクリプションにポリシーを一括適用する単位は?
