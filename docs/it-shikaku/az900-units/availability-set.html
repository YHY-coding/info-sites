ドメイン2:Azureのアーキテクチャとサービス

可用性セット(障害ドメインと更新ドメイン)

一言で言うと
同じデータセンターの中で、VMを別系統に分散して、同時に止まらないようにする仕組み。

たとえ話

同じ棟の中で、別のフロア・別の電源系統に分ける。

押さえること

  • 障害ドメイン: 電源・ネットワーク機器など物理インフラを共有する単位。最大3
  • 更新ドメイン: 計画メンテナンスで同時に再起動される単位。最大20(既定5)
  • VMを2台以上でSLA 99.95%

試験でのポイント

  • 「電源・ネットワーク」→ 障害ドメイン、「メンテナンス再起動」→ 更新ドメイン
