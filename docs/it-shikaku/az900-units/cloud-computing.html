ドメイン1:クラウドの概念

クラウドコンピューティングとは

一言で言うと
自分で設備を持たず、インターネット経由で必要な分だけ借りて、使った分だけ払う仕組み。

たとえ話

電気や水道と同じ。自宅に発電所を建てず、使った分だけ電力会社に払う。

押さえること

  • 提供側(Microsoftなど)が世界中のデータセンターに設備を用意し、利用者が必要に応じて借りる
  • 料金は従量課金(消費ベース)。止めれば、基本的に課金も止まる
  • メリット: 初期投資が不要、すぐ用意できる、増減できる、世界中に拠点がある、壊れにくい仕組みがある、保守を任せられる

試験でのポイント

  • 「初期費用なし・使った分だけ」はクラウドの特徴
  • 放置したリソースにも課金される。不要なものは削除する
