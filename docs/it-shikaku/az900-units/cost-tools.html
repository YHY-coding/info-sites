ドメイン3:Azureの管理とガバナンス

料金計算ツール・TCO計算ツール・Cost Management

一言で言うと
見積もる、比較する、実績を分析する、の3つの道具。

たとえ話

買う前の見積書、引っ越しの損得計算、運用中の家計簿アプリ。

押さえること

  • 料金計算ツール(Pricing Calculator): これから使うサービスの料金を見積もる
  • TCO計算ツール: オンプレミスとAzureのコストを比較する(移行でいくら節約できるか)
  • Microsoft Cost Management: 実際の支出の分析、予算、アラート。タグ別にも表示できる
  • 予算は、閾値に達したらアラートを出すだけ。リソースを自動停止はしない(基本は通知)

試験でのポイント

  • コスト問題の型: ①見積(これから)/比較(移行)/実績(運用中)のどれか → ②ツールを選ぶ
  • 「VMが稼働していたか」はAzure Monitorの仕事。Cost Managementではない
