ドメイン2:Azureのアーキテクチャとサービス

データ移行ツールの使い分け

一言で言うと
移行の目的ごとに、ツールが違う。

たとえ話

引っ越し業者のコースを、荷物の量と急ぎ具合で選ぶ。

押さえること

  • Azure Migrate: 移行の評価と実行の統合ハブ
  • Azure Data Box: 物理デバイスを郵送し、オフラインで大容量を移行。回線に影響しない
  • AzCopy: コマンドラインでコピー
  • Azure Storage Explorer: GUIで操作
  • Azure File Sync: オンプレのファイルサーバーとAzure Filesを継続的に同期(大量の一括移行には向かない)

試験でのポイント

  • 「大容量・短期間・回線に影響しない」→ Data Box

確認問題

大容量データを、回線に影響を与えず短期間で移行するのは?
