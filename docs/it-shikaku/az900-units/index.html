知りたい単元に、そのまま飛べる一覧です。各ページに、たとえ話、試験のポイント、似た用語へのリンク、確認問題があります。

AIを先生にして学ぶ方法
そのまま貼れる指示文つき

ドメイン1:クラウドの概念

  • クラウドコンピューティングとは
  • CapExとOpEx(資本支出と運用支出)
  • 弾力性・拡張性・機敏性の違い
  • 垂直スケーリングと水平スケーリング
  • IaaS・PaaS・SaaSの違い
  • 責任共有モデル(誰が何を管理するか)
  • パブリック・プライベート・ハイブリッドクラウド
  • サーバーレスとは

ドメイン2:Azureのアーキテクチャとサービス

  • リージョンとリージョンペア
  • 可用性ゾーン
  • 可用性セット(障害ドメインと更新ドメイン)
  • リソースの階層構造
  • リソースグループ
  • Azure Resource Manager(ARM)とIaC
  • 仮想マシンとスケールセット
  • App Service
  • コンテナ(ACIとAKS)
  • Azure FunctionsとLogic Apps
  • 仮想ネットワークとピアリング
  • VPN GatewayとExpressRoute
  • NSG(ネットワークセキュリティグループ)
  • Azure Firewall
  • ロードバランサーとApplication Gateway
  • Blob・Files・Table・Queue(ストレージ4種)
  • ストレージの冗長性(LRS・ZRS・GRS・GZRS)
  • Blobのアクセス層(ホット・クール・コールド・アーカイブ)
  • データ移行ツールの使い分け
  • Microsoft Entra ID
  • 多要素認証(MFA)
  • 条件付きアクセス・Identity Protection・PIM
  • ゼロトラストと多層防御
  • セキュリティ関連サービス(Defender・Sentinel・Key Vault・Purview)
  • 管理ツール(Portal・Cloud Shell・CLI・PowerShell)
  • Azure Arc

ドメイン3:Azureの管理とガバナンス

  • コストに影響する要因
  • 料金計算ツール・TCO計算ツール・Cost Management
  • コスト削減の手段
  • タグとリソースロック
  • Azure PolicyとAzure RBAC
  • Azure Blueprints(開店キット)
  • コンプライアンス関連の窓口
  • 監視ツール(Monitor・Advisor・Service Health)
  • SLA(稼働率の約束)
  • サポートプランとサービスのライフサイクル
