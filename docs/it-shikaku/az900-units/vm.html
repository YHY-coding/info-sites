ドメイン2:Azureのアーキテクチャとサービス

仮想マシンとスケールセット

一言で言うと
自由度が最大の仮想サーバー。OSも自分で管理するIaaS。

たとえ話

賃貸の部屋。家具(OS・ソフト)を自分で入れて管理する。

押さえること

  • VM Scale Sets: 同じVMを負荷に応じて自動で増減する(最大1000台)
  • VMを停止(割り当て解除)しても、ディスクなどのストレージ料金は続く
  • Azure Virtual Desktop: クラウド上のデスクトップ環境の配信

試験でのポイント

  • VMSSは弾力性の例。可用性セットの「分散配置」とは別の機能

確認問題

VMを停止(割り当て解除)したとき、課金が続くのは?

答えを見る

ディスクなどのストレージ料金

関連する単元

  • IaaS・PaaS・SaaSの違い
  • コストに影響する要因
