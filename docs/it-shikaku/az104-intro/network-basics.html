2. ネットワークの超基礎(電話番号と内線番号)

ネットワークでは、「相手を特定する番号(IPアドレス)」と「相手のどの窓口か(ポート番号)」の2つで、通信先が決まります。

日常のたとえ
会社に電話をかけるとき、まず代表電話番号にかけ、次に内線番号で担当者につないでもらいます。ネットワークの通信も、これと同じ2段階です。
言葉意味たとえ
IPアドレスネットワーク上で相手を特定する番号。10.3.0.15のように、数字を4つ並べる電話番号
プライベートIP社内のネットワークの中だけで使う番号。インターネットからは届かない内線専用の番号
パブリックIPインターネットから届く番号外線の番号
ポート番号1台のコンピューターの中にある、サービスごとの窓口の番号内線番号
サブネットネットワークを区切った1つの区画。10.3.0.0/24は、10.3.0.0〜10.3.0.255の範囲という意味建物のフロア
DNS名前(www.example.comなど)を、IPアドレスに変換する仕組み住所案内所(電話帳)
ファイアウォール通信を許可したり拒否したりする門番入口の警備員
プロトコル通信のルール話す言語
TCPとUDP通信の届け方の種類。TCPは確実に届ける。UDPは速さを重視する書留と普通郵便

「/24」の細かい計算は、今は気にしなくて大丈夫です。「最初の3つの数字が同じ範囲」と読めれば足ります。

よく出てくるポート番号

ポート番号担当
80Webサイト(http)
443安全なWebサイト(https)
22Linuxの遠隔操作(SSH)
3389Windowsの遠隔操作(RDP)

WebサイトのURLにポート番号を書かなくても、httpなら80番、httpsなら443番が、自動で付け足されています。つまり、通信には必ず何かのポート番号がくっついています。

言えるようになること

  • IPアドレスとポート番号の違いを、電話番号と内線番号で言える
  • プライベートIPとパブリックIPの違いを言える
  • DNSが何をするかを、一言で言える
  • 80・443・22・3389が、それぞれ何の窓口かを言える
