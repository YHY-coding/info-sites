6. コンピュート編(賃貸マンションとホテル)

コンピュートは、プログラムを動かす力を借りる話です。借り方には、自分で管理する「VM(賃貸マンション)」と、ほぼお任せの「App Service(ホテル)」があります。2つの言葉は混ぜないでください。

VM(賃貸マンション)

VMは、借りた部屋のようなものです。OS(WindowsやLinuxなど、コンピューターを動かす基本のソフト)を選び、部屋の中身は自分で管理します。

VMの「停止」は、2つの別の状態を指します(一番の引っかけ)

状態きっかけ課金
StoppedOSの中から、シャットダウンしたコンピューティングの課金は続く
DeallocatedAzureポータルの「停止」ボタン、またはaz vm deallocateコンピューティングの課金は止まる。ディスク代は続く
日常のたとえ
OSの中から電源を切るのは、電気を消しても、部屋にいる状態です。家賃は続きます。ポータルの「停止」ボタンは、本当にチェックアウトすることです。荷物(ディスク)は倉庫に預けたままなので、倉庫代だけが続きます。

チェックアウトすると、変わりうる番号(動的IP)は、別の番号になることがあります。同じ番号であってほしいなら、最初から固定(静的IP)にしておきます。

マネージドディスク

VMのデータをしまうディスクです。種類は、値段と、性能の安定性で選びます。

種類特徴主な用途
Standard HDD安くて遅く、性能にばらつきがある滅多に使わないデータ、バックアップ
Standard SSDHDDより速いが、性能の保証が緩い開発・テスト、軽い業務アプリ
Premium SSD安定して速いという保証がある本番環境の定番
Ultra Disk / Premium SSD v2超高性能・超高コスト大規模なデータベースなど

可用性セットは、VMを分散して置き、全部が同時に止まらないようにする仕組みです。障害ドメインは、物理的な故障から守ります。更新ドメインは、計画的なメンテナンスから守ります。

初回起動時の自動設定には、cloud-initという設定ファイルを使います。VMを作るコマンドを実行するときに渡す必要があり、az vm create --custom-data で行います。

Azure Migrateの推奨コア数は、実際のコア数 × 使用率 × 快適性係数で計算します。たとえば、5コア・使用率100%・係数2.0なら、10コアです。

App Service(ホテル)

設備の管理をAzure(ホテル側)がやってくれる借り方です。宿泊客は、アプリのコードだけを気にします。

たとえ実際の用語
ホテルビル本体App Serviceプラン(計算力のかたまり)
宿泊客が使う1部屋Webアプリ
予備の部屋デプロイスロット(新しいバージョンを試し、本番の部屋と入れ替える)
部屋の表札カスタムドメイン
  • 価格レベルのうち、Basicまではデプロイスロットが使えない。Standard以上で使える
  • 入れ替え(スワップ)では、コードとほとんどの設定が運ばれる。「スロット設定」にチェックした項目だけは、その部屋に残る
  • カスタムドメインの順番は、DNSの設定、ドメインの確認、SSL証明書の順

バックアップについての3つの注意

  • 保有期間の「0」は、保持しないのではなく、無期限に保持するという意味
  • バックアップの設定は、スロットごとに独立している。本番の部屋に設定しても、予備の部屋は対象にならない
  • 取得済みのバックアップは、復元先を選べる。本番のバックアップを、予備の部屋に復元することもできる

ARMテンプレート

Azureのリソースを、設計図で作る仕組みです。設計図は、JSONという決まった形式の文章で書きます。

  • パラメータは、外から渡す値。変数は、設計図の中で使う値。定義しただけでは使われず、角括弧で参照して初めて使われる
  • copyとcountで、同じ部品をまとめて複製できる。copyIndex()は、番号を振る関数で、引数なしなら0から、copyIndex(1)なら1から始まる
  • デプロイのコマンドは New-AzResourceGroupDeployment。デプロイ先のリソースグループは -ResourceGroupName で指定する

-Mode で、すでにあるリソースの扱いが変わります。

モードテンプレートに書かれていない既存のリソース
Incrementalそのまま残す。省略したときの既定
Complete削除する
日常のたとえ
模様替えの業者への指示書です。Incrementalは、「このリストの家具を追加・入れ替えして。ほかには触らないで」。Completeは、「部屋をこのリスト通りにして。リストにない家具は処分して」です。

言えるようになること

  • VMとApp Serviceの違いを、賃貸マンションとホテルで言える
  • StoppedとDeallocatedの違いを、課金で説明できる
  • 可用性セットの2つのドメインの役割を言える
  • ARMテンプレートの、角括弧とcopyIndexと、-Modeの違いを言える
