7. データベース・分析・AI・IoT・DevOps(語彙編)

この範囲は、たとえ話でさらっと語彙を押さえる範囲です。「何をするためのサービスか」を動詞で覚えます。

データベース

サービス一言
Azure SQL DatabasePaaSのマネージドSQL。OS・DBエンジンの管理不要
Azure SQL Managed InstanceSQL Serverとほぼ完全互換のマネージド(オンプレ移行向け)
SQL Server on Azure VMVM上のSQL Server=IaaS(OS管理が必要)
Azure Cosmos DBグローバル分散のNoSQL。低遅延。PaaS
Azure Database for MySQL / PostgreSQL / MariaDBオープンソースDBのマネージド版
Azure Synapse Analytics大規模データの分析(データウェアハウス)

判定の型: 「マネージドデータベース(OS・DBエンジンの管理不要、テーブルとデータだけ触る)」はPaaSです。

分析・AI

  • Azure HDInsight: Hadoop/Spark等のビッグデータクラスター。「Azure EMR」はAWSの名前で、Azureには存在しない(罠の選択肢)
  • Azure Databricks: Apache Sparkベースの分析プラットフォーム
  • Azure Machine Learning: 機械学習モデルの構築・訓練・デプロイ
  • Azure AI Services(旧Cognitive Services): 学習済みAI(画像認識・音声・言語・翻訳)をAPIで利用
  • Azure OpenAI: 大規模言語モデルのAzureでの提供

IoT

サービス一言
IoT Hubデバイスとクラウドアプリの中央メッセージハブ(双方向通信)
IoT CentralノーコードでIoTソリューションを素早く構築するSaaS的パッケージ
Azure Sphere専用チップ+専用OS+クラウドセキュリティでIoTデバイスを守る(提供状況は変わる可能性があるため公式で確認)

開発・運用

サービス一言
Azure DevOps開発チーム向け総合ツール群(Repos=バージョン管理、Pipelines=CI/CD、Boards=タスク管理、Test Plans、Artifacts)。Development+Operationsの合成語
GitHub / GitHub ActionsコードホスティングとCI/CD
Azure DevTest Labsテンプレートでラボ用VM環境を素早く作成・破棄。コストも制御

知らない単語が出たときの対処

  • 新しい単語が出たら、たとえ話で意味付けしてから先に進む。語源も有効(Dedicated=専念する、DevOps=Development+Operations)
  • 消去法で、確実に違うものを2つ消すだけで正答率は大きく上がる
  • AZ-900の範囲外の難問(AZ-104/AZ-500レベル)に出会っても気にしすぎない
