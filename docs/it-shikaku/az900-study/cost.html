10. コスト管理(料金計算ツール・TCO・Cost Management)

コストに影響する要因(試験頻出)

  1. リソースの種類(VMの大きさ、ストレージの種類)
  2. 消費量(使った時間・量)
  3. メンテナンス(ライセンスやサポート)
  4. ジオグラフィ(リージョン): 同じサービスでもリージョンで価格が違う
  5. ネットワークトラフィック: Azureに入るデータ(インバウンド)は無料、Azureから出るデータ(アウトバウンド)は課金(月の無料枠あり)。ゾーン間・リージョン間の転送も課金対象になりうる
  6. サブスクリプションの種類
  7. Azure Marketplace(サードパーティ製品の料金が別途)

課金は「使っていない=0円」とは限りません。停止したVMのディスク(ストレージ)料金は続くので、不要なものは削除します。

見積もり・分析ツールの仕分け

ツール目的一言使うタイミング
料金計算ツール(Pricing Calculator)これから使うAzureサービスの料金を見積もる買う前の見積書構築前
TCO計算ツールオンプレとAzureのコストを比較(移行でいくら節約できるか)引っ越しの損得計算移行前
Microsoft Cost Management実際の支出を分析・予算設定・アラート。タグ別にもコスト表示できる家計簿アプリ運用中
Azure Advisor(コストの推奨)未使用リソースの削減提案など-運用中
  • 予算(Budget)は、支出が閾値に達したらアラートを出すだけ。リソースを自動停止はしない(アクションを設定すればできるが、基本は通知)
  • Cost Managementで見られるのは、コストと課金に紐づく使用量。「VMが実際に稼働していたか」といった稼働状況はAzure Monitorの仕事

コスト削減の手段

手段一言
Reserved Instances(予約)1年/3年の予約で大幅割引
Azure savings plan for compute一定額/時間のコンピューティング利用を1年/3年コミットして割引。柔軟
Spot VM余剰リソースを格安に。いつでも停止されうる
Azure Hybrid Benefit手持ちのWindows Server/SQL Serverライセンスを持ち込んで割引
使っていないリソースの削除/停止(割り当て解除)未使用のコンピューティングを減らす
適切なサイズ選択(ライトサイジング)過大なVMを小さく
自動スケール負荷に合わせて台数を減らす
開発/テスト向け料金・DevTest Labs開発環境の費用を抑える
タグ部署ごとのコスト分類・責任部門の特定

割引率の最大値(予約は最大約72%、Spotは最大約90%など)は変わることがあるので、最新は公式で確認してください。

サブスクリプションの種類/購入方法

種類一言
無料アカウント期間限定のクレジット+12か月無料枠+常に無料枠(条件は公式で確認)
従量課金(Pay-As-You-Go)使った分だけ後払い
Enterprise Agreement(EA)大企業向け。複数年(一般に3年)の契約で、利用額を事前にコミット(前払い)。従量課金とは別の購入プログラム
CSP(クラウドソリューションプロバイダー)パートナー経由で購入・サポート
Visual Studioサブスクリプション(旧MSDN)開発・テスト向けのクレジット/割引

「EA=3年前払い契約」と型で覚えます(従量課金の後払いイメージで答えない)。
