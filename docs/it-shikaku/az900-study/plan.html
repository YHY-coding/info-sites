15. 学習計画と試験当日の戦略

計画は固定ではなく、模試やクイズの結果に応じて組み替えます。仕事の都合や使える時間に合わせて調整してください。

4週間プラン(標準)

週内容
第0日(準備・30分)目標日(試験日)を決める。本番を先に予約する(期限があると集中する)。最初に模試を1回受けて現状を知る
第1週: 土台作り前提知識ゼロ編 → クラウドの概念(メリット、クラウドモデル、責任共有、サーバーレス)。週末は軽く復習し、新しいことは足さない
第2週: 基盤・コンピューティング・ネットワーク物理インフラ(リージョン/ゾーン/セット/SLA)→ リソース階層・ARM → コンピューティング → ネットワーク(前半: VNet・接続、後半: NSG/FW/LB)
第3週: ストレージ・ID・セキュリティストレージ → データ/AI/IoT/DevOps(語彙)→ ID(認証/承認/Entra ID/MFA)→ ゼロトラスト・多層防御 → 管理ツール
第4週: 管理とガバナンス+仕上げコスト管理 → ガバナンス(タグ/RG/ロック/予算、Policy vs RBAC)→ 監視・SLA・サポート → 模試1回目 → 弱点の集中復習 → 模試2回目

初心者は、第1〜3週がそれぞれ1週間では収まらないことが多いです。無理に詰めず、理解が浅いまま次に進まないでください。伸ばす場合は、最難関の第2週と第3週に余裕を持たせます。

復習ルール:1-3-7日サイクル

  • 新しく学んだことは、1日後・3日後・7日後に思い出す機会を作る(忘却曲線の考え方)
  • 正解しても定着扱いにしない。日を空けて2回連続で即答できたら「定着」とみなす
  • 特に繰り返し確認するのは、「〜できますか」型の判定、SLAなどの数値、似た者ペア
  • 間違えた問題は原文のままミスログに残す(要約・削除しない)。同じ論点を2回間違えたら、弱点リストの頻度を「高」にして最優先にする
  • 弱点には、再発防止の「型」を必ず付ける(例: 「制限を増やす→サポートリクエスト」)

模試の使い方

  • 問題集ごとに難易度が違う。AZ-900の範囲を超えた難問が多い問題集では、60%台でも落ち込まなくてよい
  • 本番に近い標準的な難易度のセットで80%台が安定して出ていれば、受験してよい目安
  • 同じセットの再受験は暗記の確認にすぎず、実力の指標にならない。初見の問題でのスコアだけが実力の指標
  • 新しいセットは温存し、本番直前の「実力確認」に使う
  • 週末など空いた日の後は点が下がる(忘却)。新しい範囲に入った直後も、その範囲の点が下がる(まだ復習サイクルに乗っていないだけ)。1回の点に一喜一憂しない

単語暗記のコツ

サービス名が大量に出るので、略語だけで覚えず、フルネームから意味を理解します。

  • RBAC = Role-Based Access Control = ロールに基づくアクセス制御
  • NSG = Network Security Group = ネットワークのセキュリティの集まり(ルールのセット)
  • DevOps = Development + Operations
  • Dedicated Host = Dedicate(専念する)=自分専用の物理サーバー
  • ARM = Azure Resource Manager = Azureのリソースの管理者(管理レイヤー)
  • SLA = Service Level Agreement = サービス品質の約束

試験当日に向けて

  • オンライン受験: 事前にシステムチェック(カメラ、マイク、通信、部屋の片付け、身分証明書)。テストセンター受験: 会場・持ち物・到着時間を確認する
  • 前日: 新しい模試は触らない。弱点リストの再確認だけ。早く寝る
  • 当日の午前: 弱点リストを眺める軽い確認だけ

本番中の戦略

  1. 問題文を落ち着いて読む。「〜のみ」「すべて」「無料」などの限定的な言い切りに注意(例外がないか疑う)
  2. わからない時は消去法で、確実に違うものを2つ消す
  3. 「変更は必要ありません」形式は、下線部が正しければそれが正解。思い込みで「変更が必要」と決めつけない
  4. ケースに「Azure PowerShell」が明記されているかなど、キーワードの有無を探す
  5. 迷う問題にはフラグを立てて先に進み、最後に戻る
  6. 範囲外の難問が出ても慌てない。他の問題で取れば合格できる

結果の見方と次の道筋

  • 合格点は700/1000点(正答率70%ではなく、スケールスコア)。具体的な試験時間・問題数は、受験時の案内で確認する
  • 結果レポートには、ドメインごとの理解度の棒グラフが出る。次の学習の指針になる
資格レベル内容
AZ-900基礎クラウドとAzureの基礎
AZ-104管理者Azureの実際の管理・運用(VM、ネットワーク、ストレージ、ID、監視、バックアップ)
AZ-305設計者(上級)Azureのソリューション設計
AZ-500セキュリティAzureのセキュリティ実装

AZ-900で作った世界観と型は、AZ-104でもそのまま使えます。AZ-900で定着させた似た者ペア(NSG/Firewall、Policy/RBAC、Blob/Files)は、AZ-104でより深く問われます。AZ-104入門シリーズへ進んでください。
