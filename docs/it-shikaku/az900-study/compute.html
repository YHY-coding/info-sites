4. コンピューティングサービス(VM・App Service・コンテナ)

AZ-900で問われるコンピューティングサービスを、「何をするためのサービスか」で整理します。

サービス一言たとえ/キーワードモデル
Azure Virtual Machines(VM)自由度最大の仮想サーバー賃貸の部屋。OSも自分で管理IaaS
VM Scale Sets(VMSS)同じVMを自動で増減させる弾力性。最大1000台IaaS
可用性セット/ゾーンVMの冗長配置前の章を参照-
Azure Virtual Desktop(AVD)クラウド上のデスクトップ環境を配信リモートPC-
Azure App ServiceWebアプリ/API/モバイルバックエンドをホストホテルの部屋。OS管理不要。デプロイスロットあり。料金プランはFree/Basic/Standard/PremiumPaaS
Azure Functionsイベントでコードを実行サーバーレス。実行した分だけ課金PaaS/サーバーレス
Azure Logic Appsノーコード/ローコードのワークフロー自動化(例: メール受信→Teams通知)連携の自動化サーバーレス
Azure Container Instances(ACI)コンテナを最速・最簡単に実行(VM不要)「ポータブル」な環境=コンテナ-
Azure Kubernetes Service(AKS)多数のコンテナを管理(オーケストレーション)する大規模コンテナ運用マネージド
Azure Spot VMAzureの余剰(未使用)リソースを格安で。ただしいつでも停止される「未使用の」「余剰」のシグナル-
Azure Dedicated Host物理サーバーを1社が占有「物理サーバーを占有」のシグナル-
Azure Reserved VM Instances1年/3年の予約で割引(支払い方式)「予約」=支払いの話。物理占有ではない-

コンテナとVMの違い

VMはOSごと仮想化するので重く、起動が遅いです。コンテナはOSを共有して、アプリと依存関係だけを箱詰めするので、軽く、速く、ポータブルです。

サーバーレス系の仕分け

  • コードを書く → Functions
  • 画面でつないで自動化 → Logic Apps
  • Webアプリを動かす → App Service
  • コンテナ1つを手軽に → ACI、大規模に管理 → AKS

言えるようになること

  • VM(IaaS)とApp Service(PaaS)の違いを、賃貸とホテルで言える
  • Spot VM・Reserved・Dedicated Hostを、シグナル語で見分けられる
  • ACIとAKSの違いを言える
  • FunctionsとLogic Appsの違いを言える
