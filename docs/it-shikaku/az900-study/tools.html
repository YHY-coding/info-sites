9. 管理ツール(Portal・CLI・PowerShell・ARM・Arc)

ツール一言ポイント
Azure portalブラウザのGUIクリック操作。初心者向け
Azure Cloud Shellブラウザ上のコマンドライン(Bash/PowerShellを選べる)インストール不要、認証済み。どこでもすぐ使える
Azure CLI(azコマンド)クロスプラットフォームのCLIcmd.exe/PowerShell/Terminal/macOS/Linuxどこでも動く
Azure PowerShell(Get-Az…コマンドレット)PowerShellのAzure用モジュールPowerShell(とAzureモジュール)がインストールされている環境でのみ
Azureモバイルアプリスマホから状態確認・簡単操作-
ARMテンプレート/BicepIaC。再現性の高い自動構築-
Azure Arcオンプレ・他クラウド・エッジのサーバー/K8s/DBをAzureから一元管理管理の対象をAzure外に拡張

CLIとPowerShellのたとえ

  • Azure CLI = 合鍵: 丸い鍵穴のどの部屋(cmd/PowerShell/Terminal/Cloud Shell)でも動く
  • Azure PowerShellのコマンド = 専用の鍵: 星形の鍵穴の部屋(PowerShellがインストールされた環境)だけで動く
判定のコツ
問題文に「Azure PowerShell(モジュール)がインストールされている」と書いてあるかだけを探します。OSの種類(Windows/macOS/Linux)で可否を決めません。macOSでもAzure PowerShellモジュールを入れれば動きます。また、Windowsのコマンドプロンプトから az を実行することもできます。

学習のコツ

  • サービスは「動詞」で覚える: 同期する/見張る/探す、通す/止める、振り分ける、守る/保管する/移行する
  • 似た者ペアを必ず対で覚える(13章)
  • 範囲外の難問が出る問題集もあるので、AZ-900の範囲かどうかは公式のスキル概要で確認する
