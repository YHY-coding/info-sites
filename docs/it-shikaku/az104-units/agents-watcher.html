監視エージェントとNetwork Watcher

一言で言うと
現行の標準はAzure Monitorエージェント。ネットワーク診断はNetwork Watcher。

たとえ話

古い道具から新しい道具へ。ネットワーク専門の診断キット。

押さえること

  • Azure Monitorエージェント(AMA): 現行の標準。データ収集ルール(DCR)と連携。旧Log Analyticsエージェント(MMA)は非推奨
  • イベントサブスクリプションを作るだけでは、ゲストOSのログは収集できない。エージェントとワークスペースが必要
  • Network Watcher: 接続モニター=継続的に疎通を監視、IPフロー検証=今この瞬間の許可/拒否をその場で診断、ネクストホップ=次の中継先、トポロジ=見取り図、パケットキャプチャ=生のパケット
  • Azure Advisorは、30日を超えてVMに接続されていないディスクを検出できる

試験でのポイント

  • NSG設定後の疎通確認はIPフロー検証。継続して見るなら接続モニター
