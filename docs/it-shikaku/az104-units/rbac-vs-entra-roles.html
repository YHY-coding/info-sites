Azure RBACとEntraディレクトリロールの違い

一言で言うと
権限のシステムは2つ別々にある。リソースを操作する権限(RBAC)と、人や組織の情報を管理する権限(Entraロール)。

たとえ話

RBACは建物側の鍵、Entraロールは総務・人事のスタッフ証。

押さえること

  • Azure RBAC: 対象はVM・ストレージ・ネットワークなどのリソース。例: 所有者、共同作成者、閲覧者、ユーザーアクセス管理者
  • Entraディレクトリロール: 対象はユーザー・グループ・デバイス。例: 全体管理者、ユーザー管理者
  • 2つは別のシステムで、既定では互いにまたがらない

試験でのポイント

  • 見慣れない「〇〇管理者」は、リソースの操作権限か、ディレクトリの管理権限かをまず判定する
