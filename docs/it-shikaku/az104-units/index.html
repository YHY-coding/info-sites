AZ-104 単元別ガイド(1テーマ1ページ)

知りたい単元に、そのまま飛べる一覧です。各ページに、たとえ話、試験のポイント、似た用語へのリンク、確認問題があります。

AIを先生にして学ぶ方法
そのまま貼れる指示文つき

ID・ガバナンス

  • Azure RBACとEntraディレクトリロールの違い
  • ロール名は「後ろの役職」が権限の強さを決める
  • カスタムロールのJSON
  • グループとライセンス割り当て
  • 一括操作と外部ゲストの招待
  • ハイブリッド認証(ハッシュ同期・パススルー・AD FS)
  • 条件付きアクセス・Identity Protection・PIM
  • Azure Policyの禁止リストと階層

ネットワーク

  • NSGは「関連付けた対象」にしか効かない
  • NSGの優先度とソース欄の読み方
  • VNetピアリングは推移的ではない
  • ルートテーブルと非対称ルーティング
  • DNSの名前解決は3ステップで追う
  • Load Balancerの部品と必須パーツ
  • LB・パブリックIP・NAT GatewayのSKUをそろえる
  • Load BalancerとApplication Gatewayの違い

ストレージ

  • LRSからZRSへの変換できる種類
  • ライフサイクル管理の条件
  • 管理プレーンとデータプレーンのロール
  • SAS(共有アクセス署名)の3種類と Import/Export

コンピュート

  • App Serviceのプランとデプロイスロット
  • App Serviceのカスタムバックアップの教訓
  • VMのStoppedとDeallocated
  • マネージドディスクのパフォーマンス層
  • 可用性セットと、起動時の設定・Migrate・kubectl
  • ARMテンプレートの落とし穴(参照・copyIndex・-Mode)

監視・バックアップ

  • 診断設定の送信先(分析・保管・転送)
  • アラートルールとアクショングループの数え方
  • 監視エージェントとNetwork Watcher
  • Recovery Servicesコンテナーの削除の順番
