3. ストレージ(倉庫ビル)

ストレージで一番多い失敗は、「対応している」と「今の状態から変えられる」を同じ意味で読んでしまうことです。

  • 倉庫のグレード = ストレージアカウントの種類
  • 宅配ロッカー = BLOB
  • 共有倉庫 = ファイル共有
  • LRS / ZRS / GRS = コピー数と分散範囲

冗長性の種類

種類コピー方式範囲セカンダリから読み取り
LRS(ローカル冗長)同期1つのデータセンター内で3回コピー不可
ZRS(ゾーン冗長)同期プライマリリージョン内の3つの可用性ゾーン間不可(ゾーン障害時も読み書きは継続)
GRS(geo冗長)非同期でセカンダリへ別リージョン不可(フェールオーバーしない限り)
RA-GRS非同期でセカンダリへ別リージョン可(フェールオーバー前でも読み取れる)

LRSからZRSへの変換は、アカウントの種類で決まる

アカウントの種類ZRS自体への対応ポータルでLRSからZRSへ変換
BlobStorage非対応できない
Standard汎用v1非対応できない
Standard汎用v2対応できる
Premiumページ BLOB新規作成なら対応できない

教訓: Premiumページ BLOBのように、新規作成ならZRSにできても、あとから変換はできない種類があります。対応状況は変わることがあるので、最新は公式ドキュメントで確認してください。

日常のたとえ
倉庫のグレード(種類)によって、「コピーを複数のゾーンに置く設備」を後から増設できるかが決まります。汎用v2は増設できます。古いv1やBlobStorage専用は増設できません。Premiumページ BLOBは、最初からその設備つきで建てることはできても、建ててから増設はできません。

ライフサイクル管理

条件を満たしたBLOBを自動で安い層へ移したり、削除したりする機能です。条件のパラメータ名は、最初の1語だけが違います。

パラメータ何からの経過日数か
daysAfterCreationGreaterThanBLOBの作成後
daysAfterLastAccessTimeGreaterThan最後のアクセス(読み取り)から。事前に最終アクセス時間の追跡の有効化が必要
daysAfterModificationGreaterThan最終更新(変更)から
daysAfterLastTierChangeGreaterThan最後の層変更から

「変更」は中身を書き換えたこと。「アクセス」は読んだだけでも発生します。別の概念なので取り違えないでください。英単語に分解すると、Modification=変更、Creation=作成、LastAccessTime=最後のアクセスです。

日常のたとえ
ロッカーの中身を最後に入れ替えてからの日数が「最終変更」。誰かがロッカーを開けて見ただけでリセットされるのは「最終アクセス」です。
  • ライフサイクル管理の対象は、ブロックBLOBと追加BLOB。ページBLOBは対象外
  • 追加BLOBは「削除」しかできず、クール層への移動はできない

Azure RBAC:データを触るロールと、管理画面を見るロールは別

種類ロールの例できること
管理プレーン閲覧者、共同作成者、ストレージアカウント共同作成者アカウント自体の設定の表示・変更。BLOBの中身の読み書きは含まない
データプレーンストレージ BLOB データ共同作成者、ストレージ BLOB データ閲覧者BLOBの中身の読み書き。Entra認証でBLOBにアクセスするときに必須

Entra認証を構成したストレージで、ポータルからBLOBをアップロードさせたい場合の最小特権は、「ストレージ BLOB データ共同作成者」と「閲覧者」の2つです。データ共同作成者は書き込めますが、ストレージアカウントを表示する権限がなく、ポータルでBLOBのメニューまで辿り着けません。表示に必要な最小のロールが閲覧者です。共同作成者などは設定変更までできてしまうので過剰です。

日常のたとえ
ロッカーの鍵(データの権限)と、ビルの入館証(管理画面の権限)は別のカードです。ロッカーに荷物を入れる鍵だけ渡しても、ビルに入れなければロッカーまで行けません。

SAS(共有アクセス署名)の3種類

種類署名方式特徴
ユーザー委任SASMicrosoft Entra資格情報最も安全。マネージドIDと組み合わせるならこれ。有効期限の最大は7日間
サービスSASストレージアカウントキーBlob・Queue・Table・Filesのいずれか1つの特定リソースへのアクセスを委任
アカウントSASストレージアカウントキーサービスレベルの操作も含め、複数リソースへのアクセスを委任

Azure Import/Export

インポートは両対応、エクスポートはBLOBのみ、という非対称なルールです。エクスポート対象を聞かれたら、BLOBのみと即答できるようにします。
