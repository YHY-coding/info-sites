広告の種類(リスティング・バナー・アフィリエイト)

一言で言うと
インターネット広告には、検索結果に出すもの、画像で見せるもの、成果に応じて報酬を払うものなど、仕組みの違う型がある。

たとえ話

リスティングは「探している人の目の前に出す看板」、バナーは「通りに掲げる大きな垂れ幕」、アフィリエイトは「紹介してくれた人にお礼を払う口コミ」。

押さえること

  • リスティング広告(検索連動型広告)は、利用者が入力した検索キーワードに関連して、検索結果の画面に表示される広告
  • バナー広告は、Webページの一部に画像や動画で表示する広告。商品を知らない人にも見てもらいやすい
  • アフィリエイト(成果報酬型)広告は、個人サイトなどに広告を載せてもらい、購入や申込みなど成果が出たときに報酬を払う仕組み
  • 課金方式には、表示回数に応じるもの、クリック数に応じるもの、成果に応じるものなどがある
  • リターゲティング広告は、一度サイトを訪れた人に、あとから関連広告を表示する手法
  • 広告であることを利用者が分かるようにするなど、表示のルールにも注意が必要。細部は公式で確認

試験でのポイント

  • 「検索キーワードに連動して表示」→ リスティング広告
  • 「成果が出たときに報酬」→ アフィリエイト
