QC七つ道具と新QC七つ道具

一言で言うと
品質管理の分析の道具。名前と使い道を結びつける。

たとえ話

道具箱の工具。何を測り、何に使うかが違う。

押さえること

  • パレート図: 件数順の棒グラフ+累積の折れ線。重要な少数に絞る。特性要因図: 原因を魚の骨の形で整理。散布図: 2つのデータの相関を見る
  • ヒストグラム: 分布・ばらつき。管理図: 異常の早期発見。チェックシート: 漏れなく記録。層別: データをグループに分ける考え方
  • 新QC七つ道具(言語データ): 親和図法=グループ化、連関図法=原因の絡み合い、系統図法=目的から手段へのツリー、アローダイアグラム法=作業の順序と日程

試験でのポイント

  • 相関があっても、因果関係があるとは限らない
