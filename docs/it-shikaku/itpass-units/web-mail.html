Webとメールの仕組み

一言で言うと
メールは、送信(SMTP)と受信(POP3/IMAP4)で使うプロトコルが違う。

たとえ話

郵便の、投函と、受け取りの違い。

押さえること

  • HTTP/HTTPS: Webの通信。HTTPSは暗号化版
  • SMTP: メールの送信・中継。POP3: メールを受信してダウンロード。IMAP4: サーバ上のメールを管理しながら受信
  • Cc: 写しを送る(他の宛先にも見える)。Bcc: 受信者に見えない宛先。MIME: メールに文字以外のデータを付ける仕組み。RSS: サイトの更新情報を配信

試験でのポイント

  • 一斉送信で、受信者同士のアドレスを見せたくないときはBcc
