レビューの種類(ウォークスルー・インスペクション)

一言で言うと
レビューは、成果物を複数人で確認して欠陥を早く見つける活動。作成者が説明しながら進めるのがウォークスルー、役割と手順を決めて厳密に行うのがインスペクション。

たとえ話

作文の添削にたとえると、書いた本人が友人に読み聞かせて意見をもらうのがウォークスルー。進行役や記録係を決めて、チェック項目に沿って厳密に校閲会を開くのがインスペクション。

押さえること

  • レビューは、設計書やプログラムなどの成果物を、作成者以外の目も入れて確認し、早い段階で欠陥を見つける活動
  • ウォークスルーは、作成者が成果物を説明しながら、参加者が疑問や指摘を出していく比較的ゆるやかな形式
  • インスペクションは、進行役や記録役などの役割を決め、事前にチェック項目を用意して、手順に沿って進める形式的なレビュー
  • ほかに、成果物を事前に読んだ人が書面で意見を出す、といった軽い形式のレビューもある
  • 欠陥を早く見つけるほど修正の手間が小さいため、設計工程の成果物にもレビューを行う
  • レビューは、プログラムを実行せずに確認する点で、実際に動かして確認するテストとは異なる
  • 各形式の細かな定義や名称は、教材や標準によって違う場合があるため、用語の違いは公式の資料で確認する

試験でのポイント

  • 作成者が説明しながら進める=ウォークスルー、役割と手順が厳格=インスペクション、と対比して覚える
  • レビューは「実行せずに」確認する、テストは「実行して」確認する、と区別する
