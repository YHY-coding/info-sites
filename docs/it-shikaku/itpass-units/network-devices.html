テクノロジ系:ネットワーク

ネットワークの種類と機器(ハブ・スイッチ・ルータ)

一言で言うと
機器は、どの階層で働くかで整理する。

たとえ話

ハブ=全員に聞こえる大声、スイッチングハブ=宛先の席にだけ届ける、ルータ=別のネットワークへの郵便局。

押さえること

  • LAN: 構内のネットワーク。WAN: 広域のネットワーク。VPN: 暗号化した専用トンネル
  • ハブ: 全ポートに送る。スイッチングハブ(L2スイッチ): MACアドレスで宛先ポートだけに送る。ルータ: IPアドレスで、異なるネットワーク間を中継する。ゲートウェイ: 異なる規格をつなぐ
  • リピータ: 信号を増幅。アクセスポイント: 無線LANの親機

試験でのポイント

  • ネットワークをまたぐ中継はルータ
