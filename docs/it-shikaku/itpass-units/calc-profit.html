計算問題の型(例題つき)

売上・原価・利益の計算

一言で言うと
利益の段階を、順番に計算する型。売上総利益、営業利益、経常利益、当期純利益。

たとえ話

家計簿で、収入から出費を順に引いていく。

押さえること

  • 売上原価 = 期首棚卸高 + 当期仕入高 − 期末棚卸高。売上総利益 = 売上高 − 売上原価
  • 営業利益 = 売上総利益 − 販売費及び一般管理費。経常利益 = 営業利益 + 営業外収益 − 営業外費用
  • 原価に利益率をかけて、売値を出す問題もある: 売値 = 原価 ÷ (1 − 利益率) か、原価 × (1 + 利益率) か、問題文の定義を確認する

試験でのポイント

  • 「原価の何%の利益」と「売値の何%の利益」は別物。基準を読む

確認問題

売上高2億円、期首棚卸3,000万円、仕入1億円、期末棚卸2,000万円のとき、売上原価は?

答えを見る

1億1,000万円(3,000万+1億−2,000万)
