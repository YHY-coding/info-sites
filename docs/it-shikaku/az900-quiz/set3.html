問21 管理者権限を、必要なときだけ一時的に付与するサービスはどれか。
  • ア Identity Protection
  • イ PIM
  • ウ 条件付きアクセス
  • エ Key Vault
答えを見る

正解: イ PIM

PIM(Privileged Identity Management)。

問22 パスワードや証明書などの資格情報を、安全に保管するサービスはどれか。
  • ア Purview
  • イ Sentinel
  • ウ Key Vault
  • エ Advisor
答えを見る

正解: ウ Key Vault

Key Vault。

問23 特定のリージョンでしか、リソースを作れないようにしたい。使う機能はどれか。
  • ア Azure RBAC
  • イ Azure Policy
  • ウ リソースロック
  • エ タグ
答えを見る

正解: イ Azure Policy

場所や性質の制約はPolicy。人の権限はRBAC。

問24 リソースグループに付けたタグは、中のリソースに自動で付くか。
  • ア 自動で付く
  • イ 付かない
  • ウ 付くが読み取り専用
  • エ 管理者のみ付く
答えを見る

正解: イ 付かない

タグは自動継承されない。
