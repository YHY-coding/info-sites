問21 3つのシグナルの通知先が「AとB」「AとB」「Aのみ」のとき、アクショングループの最小数はいくつか。
  • ア 1
  • イ 2
  • ウ 3
  • エ 4
答えを見る

正解: イ 2

通知先の組み合わせのパターンの数だけ必要。

問22 NSGを設定した直後に、特定の通信が今許可されるかを、1回だけ確認できる機能はどれか。
  • ア 接続モニター
  • イ IPフロー検証
  • ウ トポロジ
  • エ パケットキャプチャ
答えを見る

正解: イ IPフロー検証

IPフロー検証。

問23 Recovery Servicesコンテナーを削除するとき、最初にすることはどれか。
  • ア コンテナーの削除
  • イ バックアップの停止
  • ウ VMの電源を切る
  • エ ポリシーの削除
答えを見る

正解: イ バックアップの停止

停止→データ削除→コンテナー削除の順。

問24 現行の標準となっている、Azure Monitorのデータ収集エージェントはどれか。
  • ア Azure Monitorエージェント
  • イ 旧Log Analyticsエージェント(MMA)
  • ウ Azure Diagnostics拡張機能
  • エ Connected Machineエージェント
答えを見る

正解: ア Azure Monitorエージェント

現行の標準はAzure Monitorエージェント(AMA)。
