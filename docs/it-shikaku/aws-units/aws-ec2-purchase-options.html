EC2の購入オプション(深掘り)

一言で言うと
EC2は使い方に合わせて、オンデマンド・リザーブド・Savings Plans・スポットなどの支払い方法を選べる。

たとえ話

車の利用に例えると、都度レンタル(オンデマンド)、長期契約(リザーブド/Savings Plans)、空き車両の格安貸出(スポット)。

押さえること

  • オンデマンド: 使った分だけ支払う。短期や予測できない利用に向く
  • リザーブドインスタンス・Savings Plans: 一定期間の利用を約束して割引を受ける。安定した利用に向く
  • スポットインスタンス: 余っている容量を割安で使える。中断される可能性があるため、中断されても困らない処理に向く
  • Dedicated Hosts: 物理サーバーを専有して使う。ライセンス要件などで必要になる場合がある
  • 割引率や契約条件の詳細は変わることがあるため、公式で確認

試験でのポイント

  • 「中断されてもよい処理を安く」→ スポット
  • 「長期で安定して使うので割引を受けたい」→ リザーブド/Savings Plans
