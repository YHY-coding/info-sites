ドメイン2:セキュリティとコンプライアンス

責任共有モデル

一言で言うと
AWSは「クラウドのセキュリティ」、利用者は「クラウド内のセキュリティ」に責任を持つ。

たとえ話

賃貸の、建物は大家、部屋の中の鍵は住人。

押さえること

  • AWSの責任: データセンター、ハードウェア、ネットワーク、ホストのOS・仮想化など(クラウド「の」セキュリティ)
  • 利用者の責任: データ、IAM、OSのパッチ(EC2の場合)、ネットワークの設定、暗号化の設定など(クラウド「内」のセキュリティ)
  • サービスによって、責任の範囲が変わる(マネージドサービスでは、AWSの担当が増える)

試験でのポイント

  • データとアクセス管理は、常に利用者の責任
