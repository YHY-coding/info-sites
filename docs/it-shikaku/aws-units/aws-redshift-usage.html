Redshiftの用途

一言で言うと
Amazon Redshiftは、大量のデータを集めて分析するためのデータウェアハウス(マネージド)サービス。SQLで集計や分析ができる。

たとえ話

日々の取引を書き留める帳簿が通常のデータベース、全店舗の帳簿を集めて傾向を調べる分析専用の大きな資料室がデータウェアハウス。

押さえること

  • 用途の中心は分析(集計・レポート・BI)。日々の細かい更新を大量に処理する業務用データベースとは役割が違う
  • SQLで扱えるので、既存のBIツールと組み合わせて使うことが多い
  • 大量データを速く集計するために、列単位でデータを持つ仕組みや並列処理を使う(詳細な仕様は公式で確認)
  • S3に置いたデータを分析対象にする連携もある(機能の範囲は公式で確認)
  • 通常の業務処理にはRDSやAuroraなど、キーでの高速な読み書きにはDynamoDBを検討する

試験でのポイント

  • 「データウェアハウス・大規模な分析」→ Redshift
  • 「業務用リレーショナルDB」→ RDS / Aurora
