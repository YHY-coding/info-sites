ドメイン4:請求・料金・サポート

一括請求と無料利用枠

一言で言うと
複数のアカウントの請求を、まとめる。

たとえ話

グループ会社の請求を、親会社にまとめる。

押さえること

  • Organizationsの一括請求: 複数のアカウントの料金を、まとめて請求。利用量が合算されるので、ボリュームディスカウントを受けやすい
  • 無料利用枠: 無料のもの(常に無料、12か月間、トライアル)がある。条件は変わるので、公式で確認
  • データ転送: AWSへの転送(インバウンド)は、基本的に無料。AWSから外への転送(アウトバウンド)には、料金がかかる

試験でのポイント

  • インバウンドは無料、アウトバウンドは有料が基本
