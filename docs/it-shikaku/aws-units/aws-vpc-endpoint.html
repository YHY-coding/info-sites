VPCエンドポイントとPrivateLink

一言で言うと
インターネットを通らずに、VPCからAWSサービスなどへプライベートに接続する仕組み。

たとえ話

オフィス内の専用通路で別フロアの部署へ行くようなもの。いったん外の道路に出なくて済む。

押さえること

  • VPCエンドポイントは、VPC内のリソースからAWSサービスへ、インターネットを経由せず接続する
  • ゲートウェイ型は、S3とDynamoDB向けで、ルートテーブルに経路を追加して使う
  • インターフェイス型は、サブネット内のネットワークインターフェイス(プライベートIP)を使って接続する
  • PrivateLinkは、サービスをVPC間やアカウント間で、プライベートに公開・利用するための仕組み
  • NATゲートウェイを経由せずに済む場合があり、通信の経路を閉じた範囲に保てる
  • 対応サービスや料金の詳細は公式で確認

試験でのポイント

  • 「インターネットを通さずAWSサービスへ接続」→ VPCエンドポイント
  • 「S3とDynamoDB向けのゲートウェイ型」→ ゲートウェイエンドポイント
