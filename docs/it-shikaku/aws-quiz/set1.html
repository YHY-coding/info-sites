AWSクラウドプラクティショナー 4択問題集 第1回

問1 AWSの責任共有モデルで、利用者の責任となるものはどれか。
  • ア データセンターの物理的な警備
  • イ ハードウェアの保守
  • ウ EC2のOSのパッチ適用
  • エ ホストの仮想化基盤
答えを見る

正解: ウ EC2のOSのパッチ適用

EC2のOSの管理は、利用者の責任。物理的な部分はAWS。

問2 需要に合わせて、リソースを自動で増減できる特性はどれか。
  • ア 弾力性
  • イ 固定費
  • ウ オンプレミス
  • エ 専有
答えを見る

正解: ア 弾力性

弾力性(エラスティシティ)。

問3 Well-Architectedフレームワークの柱に含まれないものはどれか。
  • ア 運用上の優秀性
  • イ 信頼性
  • ウ コスト最適化
  • エ 広告収益の最大化
答えを見る

正解: エ 広告収益の最大化

6つの柱は、運用上の優秀性・セキュリティ・信頼性・パフォーマンス効率・コスト最適化・持続可能性。

問4 アプリを変更せずに、そのままクラウドに移す移行戦略はどれか。
  • ア リホスト
  • イ リファクタリング
  • ウ リパーチェス
  • エ 廃止
答えを見る

正解: ア リホスト

リホスト(リフト&シフト)。

問5 AWSアカウントのルートユーザーについて、適切な対応はどれか。
  • ア 日常の作業に使う
  • イ アクセスキーを共有する
  • ウ MFAで保護し、日常では使わない
  • エ パスワードを使い回す
答えを見る

正解: ウ MFAで保護し、日常では使わない

ルートユーザーはMFAで保護し、日常の作業では使わない。

問6 EC2上のアプリに、S3へのアクセス権限を与える適切な方法はどれか。
  • ア アクセスキーをコードに埋め込む
  • イ IAMロールを割り当てる
  • ウ ルートユーザーの認証情報を使う
  • エ S3を公開する
答えを見る

正解: イ IAMロールを割り当てる

IAMロール。

問7 DDoS攻撃から、AWSのリソースを保護するサービスはどれか。
  • ア AWS Shield
  • イ Amazon Macie
  • ウ AWS KMS
  • エ AWS Config
答えを見る

正解: ア AWS Shield

AWS Shield。

問8 S3内の個人情報などの機密データを、検出するサービスはどれか。
  • ア Amazon Macie
  • イ Amazon GuardDuty
  • ウ AWS CloudTrail
  • エ Amazon Inspector
答えを見る

正解: ア Amazon Macie

Amazon Macie。

問9 AWSアカウントでの、操作(API呼び出し)を記録するサービスはどれか。
  • ア CloudWatch
  • イ CloudTrail
  • ウ Trusted Advisor
  • エ Route 53
答えを見る

正解: イ CloudTrail

CloudTrail。

問10 セキュリティグループの特徴として、正しいものはどれか。
  • ア サブネット単位で動作する
  • イ 拒否ルールを設定できる
  • ウ ステートフルで、許可ルールのみ
  • エ ステートレス
答えを見る

正解: ウ ステートフルで、許可ルールのみ

セキュリティグループは、ステートフルで、許可ルールのみ。
