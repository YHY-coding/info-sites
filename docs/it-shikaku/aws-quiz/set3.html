問21 非同期で、メッセージを受け渡すキューのサービスはどれか。
  • ア Amazon SNS
  • イ Amazon SQS
  • ウ Amazon Lex
  • エ Amazon Polly

正解: イ Amazon SQS

SQS。SNSは、通知の配信。

問23 長期の利用を約束して、EC2の料金を大幅に割引できる購入オプションはどれか。
