AWSクラウドプラクティショナー 4択問題集 第8回

問71 AWSのインフラ構成をテンプレートとしてコード化し、同じ環境を繰り返し自動で構築したい。最も適切なサービスはどれか。
  • ア AWS CloudFormation
  • イ Amazon Route 53
  • ウ AWS Direct Connect
  • エ Amazon Polly
答えを見る

正解: ア AWS CloudFormation

CloudFormationは、テンプレートに基づいてリソースをスタックとして作成・更新・削除できる。

問72 アプリケーションのコードをアップロードするだけで、実行環境の用意や負荷分散、自動増減などをAWSが自動的に構成するサービスはどれか。
  • ア Elastic Beanstalk
  • イ AWS Config
  • ウ Amazon Macie
  • エ AWS Backup
答えを見る

正解: ア Elastic Beanstalk

Elastic Beanstalkは、コードを渡すと環境の構築と管理をAWSが行う。裏ではEC2などが使われる。

問73 コンテナを実行する際、サーバーのプロビジョニングや管理を行わずに済む、ECSやEKSで選べる実行方式はどれか。
  • ア AWS Fargate
  • イ AWS Snowball
  • ウ Amazon Glacier
  • エ AWS Direct Connect
答えを見る

正解: ア AWS Fargate

Fargateは、コンテナを動かすためのサーバー管理をAWSに任せられる実行方式。

問74 AWS Lambdaの説明として、最も適切なものはどれか。
  • ア サーバーを管理せずコードを実行でき、実行した分に応じて課金される
  • イ 常時起動の仮想サーバーを月額固定で貸し出す
  • ウ 物理サーバーを自社のデータセンターに設置する
  • エ 長時間の処理を無制限に実行できる
答えを見る

正解: ア サーバーを管理せずコードを実行でき、実行した分に応じて課金される

Lambdaはサーバー管理不要のイベント駆動の実行サービスで、従量課金が基本。実行時間には上限がある。

問75 APIの作成・公開・管理を、マネージドサービスとして提供するAWSのサービスはどれか。
  • ア Amazon API Gateway
  • イ Amazon EBS
  • ウ AWS Shield
  • エ Amazon Glacier
答えを見る

正解: ア Amazon API Gateway

API GatewayはAPIの入口として、リクエストの受付、認証、流量制限などを担い、Lambdaなどのバックエンドにつなぐ。

問76 送信側と処理側を切り離し、メッセージを一時的に溜めて、処理側が取りに行く形で受け渡すAWSサービスはどれか。
  • ア Amazon SQS
  • イ Amazon SNS
  • ウ Amazon Route 53
  • エ AWS CloudTrail
答えを見る

正解: ア Amazon SQS

SQSはキュー型のサービス。SNSは複数の宛先への一斉配信、EventBridgeは条件による仕分けが得意。

問77 複数の処理を、順番・分岐・エラー時の再試行を含む流れとして定義し、実行を管理したい。適切なサービスはどれか。
  • ア AWS Step Functions
  • イ Amazon S3
  • ウ Amazon Route 53
  • エ AWS Artifact
答えを見る

正解: ア AWS Step Functions

Step Functionsは、ステートマシンとして処理の流れを組み立てるサービス。個々の処理はLambdaなどに任せられる。

問78 複数のAWSアカウントの環境を、推奨される構成とガードレールで素早く整えて管理したい。適切なサービスはどれか。
  • ア AWS Control Tower
  • イ Amazon Polly
  • ウ AWS Snowball
  • エ Amazon Kinesis
答えを見る

正解: ア AWS Control Tower

Control Towerは、ランディングゾーンとガードレールによって、複数アカウント環境を標準化して管理する。

問79 センサーやログから絶え間なく届くデータを受け取り、複数のアプリケーションが読み取れるよう一定期間保持するサービスはどれか。
  • ア Kinesis Data Streams
  • イ Amazon S3 Glacier
  • ウ AWS Backup
  • エ Amazon Route 53
答えを見る

正解: ア Kinesis Data Streams

ストリーミングデータの受け取りと保持は Kinesis Data Streams。保存先へ届けるだけなら Firehose も候補になる。

問80 S3に置いたデータへ、サーバーを用意せずに標準的なSQLで直接問い合わせたい。最も適したサービスはどれか。
  • ア Amazon Athena
  • イ Amazon EMR
  • ウ AWS Glue DataBrew
  • エ Amazon ElastiCache
答えを見る

正解: ア Amazon Athena

S3上のデータにSQLで問い合わせるのがAthena。EMRは分散処理クラスタ、GlueはETLとデータカタログが中心。
