AWSクラウドプラクティショナー 4択問題集 第5回

問41 オンプレミスのアプリを大きく変えずに、AWSのストレージへつないで利用したい。適切なサービスはどれか。
  • ア AWS Storage Gateway
  • イ Amazon Route 53
  • ウ AWS Shield
  • エ Amazon SNS
答えを見る

正解: ア AWS Storage Gateway

Storage Gatewayは、オンプレミスとAWSのストレージをつなぐハイブリッド向けサービス。

問42 複数のAWSサービスのバックアップを、ポリシーに基づいて一元的に管理したい。適切なサービスはどれか。
  • ア AWS Backup
  • イ AWS Config
  • ウ Amazon Route 53
  • エ AWS Shield
答えを見る

正解: ア AWS Backup

AWS Backupは、バックアッププランで頻度や保持期間を定め、複数サービスのバックアップを一元管理する。

問43 ほとんどアクセスしない長期保管データを、低コストで保存したい。適切なストレージはどれか。
  • ア S3 Glacier系のストレージクラス
  • イ EBSのプロビジョンドIOPS
  • ウ インスタンスストア
  • エ ElastiCache
答えを見る

正解: ア S3 Glacier系のストレージクラス

Glacier系は長期保管向けで安価。取り出しには時間がかかり、急ぐほど料金が高くなるのが基本。

問44 RDSで読み取りの負荷を分散したい。適切な機能はどれか。
  • ア リードレプリカ
  • イ マルチAZ
  • ウ S3バージョニング
  • エ Auto Scalingグループのみ
答えを見る

正解: ア リードレプリカ

読み取り専用の複製を使うリードレプリカが負荷分散向け。マルチAZは主に可用性のための機能。

問45 MySQL互換のまま、高い性能と可用性を求めるマネージドなデータベースはどれか。
  • ア Amazon Aurora
  • イ Amazon S3
  • ウ AWS Lambda
  • エ Amazon CloudFront
答えを見る

正解: ア Amazon Aurora

AuroraはMySQL・PostgreSQL互換で、複数AZにまたがる自動複製などにより高い可用性を実現する。

問46 サーバーの管理が不要で、キーによる高速な読み書きに向いたAWSのNoSQLデータベースはどれか。
  • ア Amazon DynamoDB
  • イ Amazon RDS for MySQL
  • ウ Amazon Redshift
  • エ AWS Direct Connect
答えを見る

正解: ア Amazon DynamoDB

DynamoDBはフルマネージドなNoSQLで、キーによる読み書きに強い。RDSはリレーショナル、Redshiftは分析向け。

問47 頻繁に読み取られるデータをメモリに置いて高速に返し、データベースの負荷を減らすために使うAWSサービスはどれか。
  • ア Amazon ElastiCache
  • イ AWS CloudTrail
  • ウ AWS Backup
  • エ Amazon Route 53
答えを見る

正解: ア Amazon ElastiCache

ElastiCacheはインメモリキャッシュのマネージドサービス。CloudTrailは操作の記録、Backupはバックアップ、Route 53はDNS。

問48 大量のデータを集めて、SQLで集計や分析を行うためのデータウェアハウスとして使うAWSサービスはどれか。
  • ア Amazon Redshift
  • イ Amazon ElastiCache
  • ウ AWS IAM
  • エ Amazon SQS
答えを見る

正解: ア Amazon Redshift

Redshiftは分析向けのデータウェアハウス。ElastiCacheはキャッシュ、IAMは認証・認可、SQSはメッセージキュー。

問49 オンプレミスのデータベースのデータをAWS上のデータベースへ移行するために使うサービスはどれか。
  • ア AWS DMS
  • イ Amazon CloudFront
  • ウ AWS Shield
  • エ Amazon SNS
答えを見る

正解: ア AWS DMS

DMSはデータベース移行用。CloudFrontはCDN、Shieldは攻撃対策、SNSは通知サービス。
