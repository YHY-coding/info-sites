進数変換の手計算のやり方

10進数 → n進数(割り算の方法)

変換したい数をnで割り、余りを記録します。商が0になるまで繰り返し、余りを下から上へ並べると答えです。

例: 10進数の45を2進数に

割り算商余り
45 ÷ 2221
22 ÷ 2110
11 ÷ 251
5 ÷ 221
2 ÷ 210
1 ÷ 201

余りを下から読むと 101101。つまり 45 = 101101(2進数)です。

n進数 → 10進数(重みの足し算)

各桁の数に、その桁の重み(nのべき乗)をかけて足します。

例: 2進数 101101 = 32+0+8+4+0+1 = 45。16進数 2D = 2×16 + 13 = 45。

2進数 ⇔ 16進数

2進数を右から4桁ずつ区切って、それぞれを16進1桁にします。101101 は 0010 1101 なので、2 と D で 2D です。逆は、16進1桁を4桁の2進数に戻します。
