2進数の基本

2進数は、0と1の2種類の数字だけで数を表す方法です。コンピュータは、内部の電気的な状態(オンとオフ)を0と1に対応させて情報を扱います。

桁の重み

10進数では、右から1の位・10の位・100の位…と、10倍ずつ重みが増えます。2進数では、右から1・2・4・8・16…と2倍ずつ増えます。

桁(右から)8桁目7654321桁目
重み1286432168421
例: 1101 011011010110

上の例は 128+64+16+4+2 = 214 です。

ビットとバイト

  • 1ビット: 0か1の1桁
  • 1バイト: 8ビット。0〜255の256通りを表せる
  • nビットで表せる値の種類は、2のn乗通り
