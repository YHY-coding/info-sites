16進数の基本

16進数は、1桁で16種類を表す方法です。0〜9に加えて、10〜15をA〜F(a〜f)で表します。

10進101112131415
16進ABCDEF

2進数との相性が良い理由

2進数の4桁(4ビット)は、ちょうど16通りです。そのため、2進数を右から4桁ずつ区切ると、16進数の1桁に対応します。

例: 1101 0110 → D(1101) と 6(0110) で、16進数の D6 になります。10進数では 214 です。

書き方の慣習

  • プログラミング言語では、0x を先頭に付けて 0xD6 と書くことが多い
  • HTMLの色指定では、# を付けて #ff8800 のように書く

書き方は言語やツールによって異なるため、使う環境の公式ドキュメントで確認してください。
