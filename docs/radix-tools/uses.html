進数が使われる場面

色コード

Webの色指定 #RRGGBB は、赤・緑・青をそれぞれ00〜ffの16進2桁(0〜255)で表したものです。

メモリアドレス・バイト列

データの中身(バイト列)やメモリの位置は、1バイトを16進2桁で表すと読みやすいため、16進数で示されることが多いです。

ファイルの権限

UNIX系OSでは、権限を8進数で書く慣習があります(8進数の基本)。

文字コード

文字には番号が割り当てられており、その番号は16進数で書かれることが一般的です(例: Unicodeのコードポイント)。割り当ての詳細は公式の規格で確認してください。

ネットワーク

機器の識別に使うMACアドレスは、16進数で表記されます。IPv6アドレスも16進数で書きます。

ビット演算

フラグの管理やマスク処理では、2進数・16進数で考えると分かりやすくなります(ビット演算ツール)。
