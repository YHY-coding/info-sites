割合計算の手計算のやり方

10%と1%を基準にする

10%は10で割る、1%は100で割ることで求まります。例: 8,000円の15% → 10%は800、5%はその半分の400、合わせて1,200。

約分で割合を出す

36は120の何%か: 36/120 を約分して 3/10 → 30%。

増減後の値

○%増は (1 + ○/100) 倍、○%減は (1 − ○/100) 倍します。例: 2,500円の20%減 → 2,500 × 0.8 = 2,000円。

検算

逆算で元に戻るか確かめます。2,000 ÷ 0.8 = 2,500。計算結果は割合の値のツールと見比べてください。
