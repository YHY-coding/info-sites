年収から手取りを計算

年収(万円)を入れると、社会保険料・税金を引いた手取りの目安がわかります。

計算の前提

  • 給与のみ、独身、扶養なし、賞与は月給に均等割り
  • 健康保険5.0%、厚生年金9.15%、雇用保険0.55%(いずれも本人負担の概算)
  • 所得税は令和7年度税制改正後の給与所得控除・基礎控除を使用、復興特別所得税2.1%を加算
  • 住民税は所得割10%+均等割5,000円(自治体で差があります)
