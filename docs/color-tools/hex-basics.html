16進数のカラーコードの読み方

カラーコード「#rrggbb」は、赤・緑・青の強さを16進数2桁ずつで並べたものです。16進数は0〜9とa〜f(10〜15)を使い、2桁で0〜255を表せます。

読み方の例

「#ff8800」は、赤=ff(255)、緑=88(136)、青=00(0)です。16進数の2桁は「上の桁×16+下の桁」で数に直せます(88なら8×16+8=136)。

HEXRGB色
#0000000, 0, 0黒
#ffffff255, 255, 255白
#ff0000255, 0, 0赤
#00ff000, 255, 0緑(最も明るい)
#0000ff0, 0, 255青
#808080128, 128, 128中間のグレー
#ffff00255, 255, 0黄(赤+緑)

3桁表記

各色の2桁が同じ数字の組(例: #ff8800)は、3桁に短縮して#f80と書けます。たとえば#fffは#ffffff(白)と同じです。

大文字と小文字

a〜fの大文字と小文字は同じ意味です。
