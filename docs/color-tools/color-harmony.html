配色の基本(色相環と配色パターン)

色相環は、色の種類(色相)を円に並べたものです。HSLの色相の角度(0〜360度)は、この円の位置にあたります。

パターン色相の関係印象の傾向
補色正反対(180度離れる)はっきりと目立つ
類似色隣り合う(30度ほど)まとまりがあり穏やか
トライアド120度ずつ(3色)にぎやかでバランスが取りやすい

よく言われる割合の目安

  • ベースの色: 全体の大半(背景など)
  • メインの色: 全体の中くらい
  • アクセントの色: ごく一部(目立たせたい部分)

厳密な決まりではなく、考え方のひとつです。色の数を増やしすぎないほうが整って見えやすいとされています。

印象は文化や個人、使う場面で異なります。参考のひとつとして使ってください。
