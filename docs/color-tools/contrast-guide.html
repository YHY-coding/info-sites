文字の読みやすさとコントラスト

コントラスト比は、文字色と背景色の明るさの差を1:1〜21:1の数で表したものです。白と黒の組み合わせが最大の21:1、同じ色どうしは1:1です。

よく知られる目安

Webアクセシビリティの指針(WCAG)では、通常の文字で4.5:1以上、大きい文字で3:1以上が基本の目安として示されています。大きい文字の定義など細かい条件は、公式の文書で確認してください。

見やすくするコツ

  • 明るさの差をしっかり付ける(色相の違いだけに頼らない)
  • 薄いグレーの文字を、白い背景に使いすぎない
  • 色だけで意味を伝えない(例: 赤と緑だけで状態を区別しない。文字や形も併用する)
  • 画像の上に文字を重ねるときは、背景を暗くするなどして差を確保する

計算の概要

各色のR・G・Bを、画面の明るさに近い値(相対輝度)に直し、明るい側と暗い側の比を、(明るい側+0.05)÷(暗い側+0.05)で求めます。

数値を満たしていても、読みやすさは文字の太さや大きさ、画面の環境にも左右されます。
