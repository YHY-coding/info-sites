RGB・HEX・HSLの考え方

RGB

赤(Red)・緑(Green)・青(Blue)の光の強さを、それぞれ0〜255の数で表す方法です。3つとも0なら黒、3つとも255なら白になります。光を足して色を作るため、「加法混色」と呼ばれます。

HEX(16進数表記)

RGBの3つの値を16進数の2桁ずつにして並べ、先頭に#を付けた書き方です。Webの制作でよく使われます。詳しくは16進数のカラーコードの読み方を参照してください。

HSL

色相(Hue)、彩度(Saturation)、明度(Lightness)で表す方法です。

要素範囲意味
色相0〜360度色の種類。0度が赤、120度が緑、240度が青の付近
彩度0〜100%色の鮮やかさ。0%でグレー
明度0〜100%明るさ。0%で黒、100%で白

HSLは「少し明るくする」「少し落ち着かせる」といった調整が数字で考えやすいのが利点です。

実際の見え方は、ディスプレイの設定や周囲の明るさで変わります。印刷用のCMYKとは別の仕組みです。
