単利・複利計算ツール集
単利複利積立目標年数倍になる年数基本単利と複利つまずき用語

利息計算のつまずきやすい点

1. 年利を月にそのまま使う

年利3%を、毎月3%として計算してしまうと大きくずれます。月あたりにするときは年利を12で割ります。

2. 年利を12倍・12で割る関係は厳密ではない

年利3%の月複利は、1年あたりの実質の増え方がちょうど3%にはなりません(わずかに多くなります)。表示の年利が何の回数を前提にしているかは、公式の情報で確認が必要です。

3. 積立のタイミング

月初に入金するか月末かで、結果が少し変わります。本サイトの積立ツールは月末入金のモデルです。

4. 税金・手数料は別

実際の受取額は、税金や手数料で変わることがあります。本サイトの結果には含まれません。

5. 将来の利率は変わりうる

変動する利率の場合、同じ率が続く前提の計算結果は、あくまで目安です。

本サイトの結果は概算・目安です。税金・手数料・実際の利率の変動は考慮していません。特定の商品の選択や運用の判断をすすめるものではありません。実際の条件は、各金融機関や公式の情報で確認してください。入力した値は、ブラウザの中だけで計算され、送信されません。
