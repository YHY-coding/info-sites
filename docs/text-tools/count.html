数え方

  • 1文字は、見た目の1文字ではなくUnicodeの1コードポイントとして数えます。絵文字や合成文字は、見た目より多く数えることがあります
  • 空白は、半角スペース、タブ、全角スペース、改行を指します
  • 原稿用紙の枚数は、改行を除いた文字数を400で割って切り上げた目安です。禁則処理や段落の字下げは考慮しません
  • 投稿先ごとの文字数の数え方は異なることがあります。文字数とバイト数の違いと、投稿先の公式の案内を確認してください

本サイトの結果は目安です。文字数の制限や数え方は、投稿先・提出先・応募要項などの公式の案内で確認してください。入力した文章は、ブラウザの中だけで処理され、送信されません。
