全角と半角の基礎知識

全角は日本語の文字と同じ幅で表示される文字、半角はその約半分の幅で表示される文字です。もともとは文字の見た目の幅を指す言葉で、文字コード上でも別の文字として区別されます。

混在で困りやすい場面

  • 検索や並べ替えで、全角と半角の同じ文字が別のものとして扱われることがある
  • 同じ見た目の英数字でも、全角と半角が混ざると、重複の判定や集計が合わないことがある
  • フォームやシステムが、半角のみ、または全角のみの入力を求める場合がある

統一のおおまかな考え方

  • 英数字と記号は、半角にそろえることが多い
  • 日本語の文章中のカタカナは、全角が一般的。半角カナは、互換性のため残る古い形式として扱われる
  • 最終的な書式は、提出先や利用するシステムの指定に従う
