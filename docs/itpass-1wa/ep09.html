2進数ってなに?

一言で言うと
0と1だけで、数を表す方法。
たとえるなら
スイッチのオン(1)とオフ(0)だけで、数を数える。

コンピュータは、0と1の2つだけで、すべてを扱います。これが2進数です。

2進数の各けたは、右から 1、2、4、8、16 …を表します。

例: 1101 は、8 + 4 + 0 + 1 = 13。
