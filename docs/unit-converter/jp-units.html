尺貫法の単位

尺貫法は、長さを尺、重さを貫で表す日本の伝統的な単位系です。現在、取引や証明に使える単位はメートル法が基本ですが、建築や不動産、工芸などで昔の単位が話題に出ることがあります。

単位メートル法での大きさメモ
1尺10/33m(約30.30cm)1寸の10倍
1間6尺 = 60/33m(約1.818m)建築や土地でよく使う
1里36町 = 2160間(約3.927km)1町 = 60間
1坪1間×1間 = 400/121㎡(約3.306㎡)土地・建物の面積
1匁3.75g真珠などの重さにも使われる
1貫1000匁 = 3.75kg

尺貫法の単位をメートル法に直す関係は、法令で定められた換算値にもとづくものです。取引や証明で使う場合は、公式の基準で確認してください。

長さ / 面積 / 重さのツールで換算できます。
